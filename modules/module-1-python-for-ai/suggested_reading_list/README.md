# Suggested reading: Module 1 (Python for AI)

Once you have finished Module 1, these are the best places to go deeper on Python, NumPy, Pandas, and working with APIs. All are free.

## Videos

- [Python for Beginners (full course), freeCodeCamp](https://www.youtube.com/watch?v=rfscVS0vtbw) - a single, thorough run through the language from scratch.

## Books

- [Automate the Boring Stuff with Python, Al Sweigart](https://automatetheboringstuff.com/) - practical Python for real tasks; free to read online.
- [Python for Data Analysis (3rd edition), Wes McKinney](https://wesmckinney.com/book/) - the creator of Pandas on NumPy, Pandas, and Jupyter; free online.

## Docs and tutorials

- [The Python Tutorial (official docs)](https://docs.python.org/3/tutorial/) - the canonical reference tour of the language.
- [NumPy: the absolute basics for beginners](https://numpy.org/doc/stable/user/absolute_beginners.html) - arrays, shapes, and vectorized math.
- [10 minutes to pandas](https://pandas.pydata.org/docs/user_guide/10min.html) - a fast tour of the DataFrame.
- [Requests: HTTP for humans](https://requests.readthedocs.io/) - the library behind the APIs class.
- [Real Python](https://realpython.com/) - reliable, well-edited tutorials on almost any Python topic.
