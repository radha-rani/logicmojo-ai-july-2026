Python basicsVariables and types

A variable is a labeled box. A type is the kind of thing inside it.

n = 7             # int
price = 4.5       # float
name = "Ada"      # str
is_ready = True   # bool

print(type(name)) # <class 'str'>
  • int: whole numbers, like 7.
  • float: decimals, like 4.5.
  • str: text in quotes, like "Ada".
  • bool: True or False.
  • type(x) tells you what a value is.

Python basicsf-strings

Drop values straight into text. You will use this constantly.

count = 3
print(f"count is {count}")

name, score = "Ada", 91
print(f"{name} scored {score}")
  • Start the string with an f.
  • Put any variable inside { }.
  • Format numbers too: f"{price:.2f}".
  • Cleaner than gluing strings with +.

Python basicsLists

A list is an ordered collection you can index, slice, and grow.

names = ["Ada", "Alan", "Grace"]
print(names[0])       # Ada    (index from 0)
print(names[-1])      # Grace  (last item)

names.append("Kay")   # add to the end
print(names[:2])      # ['Ada', 'Alan']  (a slice)
print(len(names))     # 4
  • Ordered: items keep their position.
  • Index from 0; -1 is the last item.
  • append adds to the end.
  • A slice like [:2] takes a piece.
  • len() counts the items.
Think of it asA numbered to-do list. Items stay in order, you add to the bottom, and you read the nth line.

Control flow · 1 of 3if: make a decision

Run different code depending on a condition.

n = -4
if n > 0:
    print("positive")
elif n < 0:
    print("negative")
else:
    print("zero")
Another one
age = 20
if age >= 18:
    print("adult")
else:
    print("minor")
  • Checks run top to bottom.
  • elif adds branches; else is the fallback.

Control flow · 2 of 3for: repeat over items

Do something once for each item in a sequence.

names = ["Ada", "Alan", "Grace"]
for person in names:
    print(person)
Count with range
for i in range(1, 4):
    print(i)   # 1, 2, 3
  • The loop body is the indented part.
  • range(1, 4) stops before 4.

Control flow · 3 of 3while: repeat until done

Keep going while a condition stays true.

k = 3
while k > 0:
    print(k)
    k -= 1
print("done")
  • Runs as long as the test is true.
  • Change something inside so it can stop.
  • k -= 1 means k = k - 1.
Watch out Forget to change k and it never stops. That is an infinite loop.

A core skillReading a traceback

In Python, indentation is the structure. When it is wrong, Python points to where.

Broken code
for name in names:
print(name)
What Python prints
  File "starter.py", line 2
    print(name)
    ^
IndentationError: expected an
indented block after 'for'
statement on line 1
  • Read the last line first: it names the error. The line above shows where.
  • Fix here: indent the print. Reading errors is normal, not a sign of failure.
