The data stack

The two libraries every AI dataset passes through: NumPy for numbers and vectors, Pandas for tables.

Recap and todayThe two libraries every dataset touches

You can structure programs and read and write data. Today you meet the tools that hold and shape that data for AI, and the operations you will reach for daily.

NumPy
  • Fast, fixed-type arrays
  • Shape and reshape; index and slice
  • Masking, broadcasting, and axis math
  • The vector: the shape of all AI data
Pandas
  • Tables you drive with code
  • Select with labels and positions
  • Filter, derive, and handle missing data
  • Group, summarize, and sort

NumPy · 1 of 8Why not just use a list?

import numpy as np

# a Python list can hold mixed, boxed objects
box = [1, "two", 3.0]

# a NumPy array is one fixed type, packed tightly
arr = np.array([1, 2, 3])
print(arr.dtype)   # int64
print(arr * 2)     # [2 4 6]  (the whole array at once)
  • A list stores scattered Python objects; an array stores one fixed type in one contiguous block.
  • That layout lets NumPy run math in fast compiled loops, not slow Python ones.
  • Operations apply to the whole array at once (vectorization), so there is nothing to loop over by hand.
Think of it asA list is a shelf of labeled boxes; an array is a ruler of identical, evenly spaced cells.

NumPy · 2 of 8Make arrays, and know their dtype

np.array([1, 2, 3])        # from a list
np.arange(0, 10, 2)        # [0 2 4 6 8]  (start, stop, step)
np.linspace(0, 1, 5)       # [0. 0.25 0.5 0.75 1.]
np.zeros(3)                # [0. 0. 0.]
np.ones((2, 3))            # a 2x3 grid of ones

np.array([1, 2, 3]).dtype          # dtype('int64')
np.array([1, 2, 3.0]).dtype        # dtype('float64')
  • arange is range for arrays; linspace(a, b, n) gives n evenly spaced points including both ends.
  • zeros and ones preallocate a grid of a given shape.
  • Every array has one dtype (int64, float64, ...). One float in the list promotes the whole array to float.

NumPy · 3 of 8Shape: how the numbers are arranged

a = np.arange(6)        # [0 1 2 3 4 5]
print(a.shape)          # (6,)     one dimension
print(a.ndim)           # 1

m = a.reshape(2, 3)     # 2 rows, 3 columns
print(m.shape)          # (2, 3)
print(m.ndim)           # 2

a.reshape(-1, 2)        # -1 = "you work out this one" -> (3, 2)
  • .shape is a tuple of sizes per dimension; .ndim is how many dimensions.
  • A 1D array is a vector; a 2D array is a matrix; more dimensions are tensors.
  • reshape re-lays the same values into a new shape; the counts must match (6 = 2 × 3).
  • -1 means "infer this dimension from the rest".

NumPy · 4 of 8Index and slice, in 1D and 2D

m = np.array([[10, 20, 30],
              [40, 50, 60]])

m[0, 2]     # 30           row 0, column 2
m[1]        # [40 50 60]   the whole second row
m[:, 0]     # [10 40]      the whole first column
m[0, :2]    # [10 20]      row 0, first two columns
  • Index a 2D array with [row, column], not [row][column].
  • A bare : means "all of this dimension", so m[:, 0] is every row's first column.
  • Slices use start:stop as in lists, and the stop is excluded.
Rows then columns The first index walks down the rows, the second across the columns. Read m[r, c] as "row r, column c".

NumPy · 5 of 8Boolean masking: select by condition

prices = np.array([40, 120, 250, 80, 15])

mask = prices > 100
print(mask)            # [False  True  True False False]
print(prices[mask])    # [120 250]   keep where True

print((prices > 100).sum())   # 2   True counts as 1

prices[prices < 50] = 0       # assign through a mask
print(prices)                 # [  0 120 250  80   0]
  • A comparison on an array returns a same-shape array of True/False.
  • Indexing with that mask keeps only the True positions.
  • Because True is 1, mask.sum() counts how many passed.
  • You can assign through a mask to change just the matching cells.

NumPy · 6 of 8Vectorized math and broadcasting

a = np.array([1, 2, 3])
print(a + 10)      # [11 12 13]   scalar stretched to each
print(a * a)       # [1 4 9]      elementwise

# broadcasting: a 1D row added to every row of a matrix
matrix = np.array([[1, 2, 3],
                   [4, 5, 6]])
bias = np.array([10, 20, 30])
print(matrix + bias)
# [[11 22 33]
#  [14 25 36]]
  • Arithmetic between arrays happens elementwise, with no loop.
  • Broadcasting: when shapes differ, NumPy stretches the smaller one to fit, if the dimensions line up.
  • Here the length-3 bias is applied to each row of the 2×3 matrix.
Why it matters Adding a bias vector across a batch of rows is exactly what a neural network layer does. You are seeing the core operation now.

NumPy · 7 of 8Aggregations, and the axis argument

scores = np.array([[90, 80],    # student 1: math, english
                   [70, 60],    # student 2
                   [85, 95]])   # student 3

scores.mean()          # 80.0            over everything
scores.sum(axis=0)     # [245 235]       down columns (per subject)
scores.sum(axis=1)     # [170 130 180]   across rows (per student)
  • sum, mean, std, min, max reduce an array to a summary.
  • With no axis, they reduce the whole array to one number.
  • axis=0 works down the rows (a result per column); axis=1 works across the columns (a result per row).
The mnemonic The axis you name is the one that disappears. axis=0 collapses the rows, leaving one value per column.

NumPy · 8 of 8All AI data is arrays of numbers

# a "meaning" is stored as a vector of numbers
a = np.array([1, 0, 2])
b = np.array([2, 1, 0])

np.dot(a, b)   # 1*2 + 0*1 + 2*0 = 2
a @ b          # same thing, the @ operator

$$ \mathbf{a} \cdot \mathbf{b} = \sum_{i} a_i b_i $$

  • Text, images, and sound all become arrays of numbers before a model sees them.
  • The dot product multiplies two vectors position by position and adds the results into a single number.
  • Read the formula as: for each index i, multiply a's and b's value there, then sum them all. A larger result means the vectors point more the same way.
  • That one number is how we will measure similarity between embeddings in Module 4.

Pandas · 1 of 11Series and DataFrame

import pandas as pd

products = pd.DataFrame({
    "name": ["pen", "notebook", "brush", "marker"],
    "category": ["office", "office", "art", "art"],
    "price": [1.5, 3.0, 4.0, 2.5],
})

products["price"]          # one column: a Series
type(products["price"])    # pandas ... Series
type(products)             # pandas ... DataFrame
  • A DataFrame is a table: rows and labeled columns, like a spreadsheet you drive with code.
  • A single column is a Series: a labeled 1D array (a NumPy array with an index on top).
  • The row labels are the index; here it defaults to 0, 1, 2, 3.

Pandas · 2 of 11Reading data: read_csv and friends

df = pd.read_csv("products.csv")   # the workhorse

# options for real-world files
pd.read_csv("data.csv", sep=";")               # other delimiters
pd.read_csv("data.csv", usecols=["name", "price"])
pd.read_csv("data.csv", na_values=["", "NA"])  # blanks -> NaN

# the reader family: each returns a DataFrame
pd.read_excel("book.xlsx")
pd.read_json("records.json")
pd.read_parquet("data.parquet")

df.to_csv("out.csv", index=False)  # readers mirror writers
  • read_csv is the one you will reach for most; a dict still works for tiny inline data.
  • Options handle messy files: a different sep, a subset of columns with usecols, blanks marked missing with na_values, dates parsed with parse_dates.
  • The whole family (read_excel, read_json, read_parquet, read_sql) returns a DataFrame, so the rest of today applies whatever the source.
  • Every reader has a matching writer (to_csv, to_parquet), so you can round-trip data back out.

Pandas · 3 of 11Look before you leap

df.head()      # first 5 rows (df.tail() for the last)
df.shape       # (rows, columns)
df.columns     # the column names
df.dtypes      # the type of each column
df.info()      # columns, non-null counts, dtypes
df.describe()  # count/mean/std/min/max for numbers
  • Always inspect before analysis: head to eyeball rows, shape for size.
  • dtypes catches a number read as text, a common cause of later bugs.
  • info reveals missing values through the non-null counts; describe summarizes the numeric columns at a glance.

Pandas · 4 of 11Select columns

# one column -> a Series
df["price"]

# several columns -> a smaller DataFrame
df[["name", "price"]]

# a Series carries array-like methods
df["price"].mean()
df["category"].unique()   # distinct values
  • One name in [ ] returns a Series; a list of names returns a DataFrame.
  • The double brackets are just a list of columns inside the selection.
  • A Series has array-like methods: .mean(), .unique(), .value_counts().
One bracket vs two df["price"] is a column; df[["price"]] is a one-column table. The shape differs, which matters when a function expects one or the other.

Pandas · 5 of 11.loc for labels, .iloc for positions

# .loc uses labels: row index and column names
df.loc[0, "name"]              # value at row-label 0, col "name"
df.loc[0:2, ["name", "price"]] # label slice (0:2 includes 2)

# .iloc uses integer positions
df.iloc[0]                     # the first row
df.iloc[0:2, 0]                # first two rows, first column
df.iloc[-1]                    # the last row
  • .loc selects by label: index values and column names. A label slice includes the endpoint.
  • .iloc selects by integer position, and like normal slicing the endpoint is excluded.
  • Reach for .loc most of the time; use .iloc when you truly mean "the nth row".

Pandas · 6 of 11Filter rows by condition

# rows where a condition is true
df[df["price"] > 2]

# combine with & (and) / | (or), each in parentheses
df[(df["price"] > 2) & (df["category"] == "art")]

# membership test
df[df["category"].isin(["art", "office"])]
  • A condition inside df[...] keeps only the rows where it is True, the same masking idea as NumPy.
  • Combine conditions with & and |, not and/or, and wrap each in parentheses.
  • .isin([...]) tests membership against a set of values.
Parentheses are not optional & binds tighter than >, so an unparenthesized condition parses wrong. Wrap each comparison.

Pandas · 7 of 11Add derived columns

import numpy as np

df["revenue"] = df["price"] * df["units"]   # column math
df["pricey"]  = df["price"] > 3             # a boolean column
df["log_u"]   = np.log(df["units"])         # NumPy on a column
  • Assign to a new column name and Pandas computes it for every row at once.
  • It is the same vectorized idea as NumPy: no loop over rows.
  • NumPy functions apply straight to a column, since a column is a Series over an array.

Pandas · 8 of 11Missing data is the norm, not the exception

df.isna().sum()      # count missing (NaN) per column

df.dropna()          # drop any row with a missing value

df.fillna(0)         # fill every missing value with 0

# fill one column with its own mean
df["price"] = df["price"].fillna(df["price"].mean())
  • Real data has gaps. Pandas marks them NaN, and .isna() finds them.
  • dropna removes rows with gaps; fillna replaces them.
  • Decide per column: drop when a row is unusable, fill (with 0, a mean, or a label) when a sensible default exists.
A silent trap A NaN in a numeric column can quietly poison a mean or a sum. Handle gaps before you compute on them.

Pandas · 9 of 11Group and summarize

# mean price per category
df.groupby("category")["price"].mean()

# several summaries at once
df.groupby("category").agg(
    avg_price=("price", "mean"),
    total_units=("units", "sum"),
)

df["category"].value_counts()   # rows per category
  • groupby(key) splits rows into groups that share a key.
  • Then you summarize each group: .mean(), .sum(), .count(), or several at once with .agg(...).
  • value_counts() is the quick "how many of each" on one column.
Split, apply, combineSplit the rows into groups, apply a summary to each, combine the results into one table.

Pandas · 10 of 11A small end-to-end pipeline

# 1. filter (copy so the next steps are safe)
big = df[df["units"] > 20].copy()

# 2. derive a column
big["revenue"] = big["price"] * big["units"]

# 3. sort by it, highest first
big = big.sort_values("revenue", ascending=False)

# 4. summarize per category
big.groupby("category")["revenue"].sum()
  • Most analysis is this shape: filter, derive, sort, group.
  • Each step returns a DataFrame, so the next step reads cleanly.
  • sort_values(col, ascending=False) orders rows; add .head(n) for a top-n.

Pandas · 11 of 11The copy trap, and the clear way

# risky: this may be a view of df, not a copy
subset = df[df["price"] > 2]
subset["price"] = 0     # SettingWithCopyWarning

# clear: select and assign in one .loc step
df.loc[df["price"] > 2, "price"] = 0

# or take an explicit copy first
subset = df[df["price"] > 2].copy()
subset["price"] = 0     # safe now
Avoid the copy trap Chained indexing like df[...][...] = ... may write to a temporary copy, not the real table, and Pandas warns you. Use .loc[rows, column] to select and assign in one step, or take an explicit .copy() when you want a separate table.
