# Suggested reading: Module 2 (ML and DL essentials)

After Module 2 you understand the training loop, neural networks, and PyTorch. These resources deepen the intuition and the practice. All are free.

## Videos

- [Neural networks series, 3Blue1Brown](https://www.3blue1brown.com/topics/neural-networks) - the best visual explanation of neurons, gradient descent, and backpropagation.
- [StatQuest with Josh Starmer](https://statquest.org/) - gradient descent, neural networks, and cross-entropy explained step by step.
- [Machine Learning Specialization, Andrew Ng (Coursera)](https://www.coursera.org/specializations/machine-learning-introduction) - the classic on-ramp to the whole field.

## Books

- [Neural Networks and Deep Learning, Michael Nielsen](http://neuralnetworksanddeeplearning.com/) - a free book that builds a network and backprop from first principles.
- [Dive into Deep Learning (d2l.ai)](https://d2l.ai/) - a free, runnable textbook with PyTorch code alongside the math.

## Docs

- [PyTorch tutorials](https://pytorch.org/tutorials/) - official, from tensors to a full training loop.
- [scikit-learn user guide](https://scikit-learn.org/stable/user_guide.html) - the reference for the library used in class 2.1.
